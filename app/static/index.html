WORKBENCH GUIDE

Two-step workflow

1. Template Generator: Click Upload DOCX in the top-right corner to upload prior client PBRER reports. Inspect the Generic Table Blueprint, review and customize detected fields and master.md, then approve.

2. Generator: Select an approved template, upload new Excel source workbooks, inspect auto-generated Markdown data dictionaries and proposed column mappings, choose the explicit counting unit, enter new-interval narratives, and build a styled DOCX copy.

Shortcuts: Press Ctrl+S while editing a draft template to save changes, and Esc to dismiss any dialog.
